# Dependency parser for Bulgarian

This is a dependency parser for Bulgarian, based on the Universal Dependencies (UD) framework. The project is still in development, and some of the descriptions may not be up-to-date with the current state of the code.

## Citation

If you use this parser in your research, please cite the following paper:
